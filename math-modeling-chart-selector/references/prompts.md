# 可直接给AI的选图与作图提示词

## 自动选图总提示词

```text
请检查[数据文件]及[字段含义、单位、每行含义]，围绕[问题或分析目标]自动选择数学建模论文图形。先分清语义类型、原始/汇总数据、配对关系、时间/地理结构、类别和样本规模、缺失与可用统计区间。
提出一个常规图和一个满足数据条件的创新候选；若创新候选没有额外信息价值或印刷后更难读，选择常规图。不要为了创新造区间、补分布或添加不存在的关系。
输出：数据画像、首选图与备选图、选择依据、推荐软件及相较备选软件的理由、可复制的绘图提示词。结合我的[软件经验/现有代码/许可证/输出格式/版面宽度]选择工具，没有信息时说明你的默认假设。
此次交付是[只选图和提示词/继续生成图与代码]。保留真实数据，披露聚合、标准化、平滑和插值；精确统计图用代码或数据绘图软件生成，AI图像工具只用于合适的概念插画。
```

## 常规图优先提示词

```text
按[论证目标]选最直接的常规图，以准确比较和清晰标签优先。只有在常规图存在明确的信息缺口时才提出创新备选，不擅自增加3D、径向或装饰背景。结合真实字段给出轴、颜色、分组、图例、单位、统计区间和图注，再说明软件选择。
```

## 创新图优先提示词

```text
在不改变数据与统计语义的前提下，为[数据与论证目标]设计一个有信息增益的创新图版。先给常规基线，再说明创新增加了什么可读信息。优先考虑主图+边际分布、全局+局部、机制+结果、空间快照+同步时序、估计+不确定性，避免仅以装饰和3D冒充创新。如果输入不足或版面不清晰，退回常规图并解释。
```

## 软件选择提示词

```text
根据[图形类型]、[数据规模]、[静态论文/交互展示]、[现有Python/R/MATLAB/GUI工作流]和[输出格式]选一个首选软件及一个备选。解释首选在数据计算、版式控制和可复现性上的具体优势，并说明导出与许可证前提。不要把“能够绘制”说成“原作者使用”，不要把熟悉程度未知时的推荐说成普遍最佳。
```
